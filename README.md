# Zenith-Finance
O Zenith simplifica o controle financeiro e de estoque para empresas. Possui leitor de código de barras para movimentação ágil e o Steev, assistente de IA que executa tarefas por comandos simples. O protótipo inclui tela principal com dados e relatórios gerais, além de chat com a IA para emitir notas fiscais, calcular gastos e alertar sobre faltas.
